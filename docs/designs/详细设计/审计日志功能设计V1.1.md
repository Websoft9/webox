## 2. 审计日志功能设计

审计日志是平台提供的对敏感业务操作的日志记录，以便于用户进行业务审计、业务事件追踪等管理需求。

- **功能描述**

1. 【审计日志查询】

支持分页查询和多条件筛选，查询条件包括：

| 查询条件 | 示例     | 描述                                                             |
| -------- | -------- | ---------------------------------------------------------------- |
| 搜索     | 关键词   | 文本输入框，支持客户端IP地址、资源名称、用户名的精确或模糊查询。 |
| 日志类别 | 应用管理 | 多选下拉选项，支持按功能模块筛选日志类别。                       |
| 操作类型 | 创建     | 多选下拉选项，支持按操作类型筛选（创建/修改/删除等）。           |
| 操作结果 | 成功     | 单选下拉选项，支持按操作结果筛选（成功/失败）。                  |
| 时间范围 | 近7天    | 日期范围选择器，支持按操作时间范围筛选。                         |

2. 【审计日志列表】

按照操作时间倒序排列，以列表方式展示审计日志，展示信息包括：

- 操作时间、日志类别、操作类型、操作结果。
- 操作按钮：查看详情、导出。

3. 【审计日志详情】

点击日志记录查看详细信息：

- 【基本信息】操作时间、操作用户、客户端信息、会话ID。
- 【操作内容】操作类型、资源信息、操作描述、请求参数。
- 【操作结果】执行结果、响应状态、错误信息（如有）。

4. 【审计日志导出】

支持审计日志的批量导出：

- 【导出格式】支持CSV、Excel、JSON格式导出。
- 【导出范围】支持按查询条件导出或全量导出。
- 【数据脱敏】导出数据自动进行敏感信息脱敏处理。
- 【导出审计】导出操作本身也会记录审计日志。

## 3. 审计日志接口设计

**获取审计日志列表**

```text
GET /api/v1/audit-logs
```

查询参数：

| 参数          | 类型    | 必填 | 默认值 | 描述     |
| ------------- | ------- | ---- | ------ | -------- |
| page          | integer | 否   | 1      | 页码     |
| page_size     | integer | 否   | 20     | 每页数量 |
| user_id       | integer | 否   | -      | 用户ID   |
| action        | string  | 否   | -      | 操作类型 |
| resource_type | string  | 否   | -      | 资源类型 |
| resource_id   | integer | 否   | -      | 资源ID   |
| start_time    | string  | 否   | -      | 开始时间 |
| end_time      | string  | 否   | -      | 结束时间 |
| ip_address    | string  | 否   | -      | IP地址   |

响应示例：

**获取审计日志详情**

```text
GET /api/v1/audit-logs/{id}
```

**获取审计统计**

```text
GET /api/v1/audit-logs/statistics
```

查询参数：

| 参数       | 类型   | 必填 | 默认值 | 描述                               |
| ---------- | ------ | ---- | ------ | ---------------------------------- |
| start_time | string | 否   | -      | 开始时间                           |
| end_time   | string | 否   | -      | 结束时间                           |
| group_by   | string | 否   | day    | 分组方式（hour, day, week, month） |

响应：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total_operations": 1250,
    "success_operations": 1200,
    "failed_operations": 50,

      }
    ],

      {

        "count": 200
      }
    ],
    "timeline": [
      {
        "date": "2025-01-22",
        "count": 150
      }
    ]
  }
}
```

**导出审计日志**

```text
GET /api/v1/audit-logs/export
```

查询参数：

| 参数       | 类型    | 必填 | 默认值 | 描述                         |
| ---------- | ------- | ---- | ------ | ---------------------------- |
| format     | string  | 否   | csv    | 导出格式（csv, excel, json） |
| start_time | string  | 否   | -      | 开始时间                     |
| end_time   | string  | 否   | -      | 结束时间                     |
| user_id    | integer | 否   | -      | 用户ID                       |

响应：

```text
Content-Type: application/octet-stream
Content-Disposition: attachment; filename="audit-logs-20250122.csv"
```

## 4. 审计日志数据库设计

**审计日志表（audit_logs）**

| 字段名          | 类型            | 约束               | 默认值            | 注释                                              |
| --------------- | --------------- | ------------------ | ----------------- | ------------------------------------------------- |
| id              | BIGINT UNSIGNED | PK, AUTO_INCREMENT | -                 | 日志ID                                            |
| user_id         | BIGINT UNSIGNED | FK                 | NULL              | 用户ID                                            |
| username        | VARCHAR(64)     | -                  | NULL              | 用户名                                            |
| action          | VARCHAR(32)     | NOT NULL           | -                 | 操作动作（详见《安全管理设计-5.1-操作权限定义》） |
| module          | VARCHAR(32)     | NOT NULL           | -                 | 模块名称（API模块英文名称）                       |
| resource_type   | VARCHAR(32)     | -                  | NULL              | 资源类型（API模块中文名称）                       |
| resource_id     | BIGINT UNSIGNED | FK                 | NULL              | 资源ID（原始记录ID）                              |
| resource_name   | VARCHAR(64)     | -                  | NULL              | 资源名称（原始记录表名称）                        |
| description     | TEXT            | -                  | NULL              | 操作描述                                          |
| ip_address      | VARCHAR(45)     | -                  | NULL              | IP地址                                            |
| user_agent      | VARCHAR(255)    | -                  | NULL              | 用户代理                                          |
| request_method  | VARCHAR(10)     | -                  | NULL              | 请求方法                                          |
| request_url     | VARCHAR(255)    | -                  | NULL              | 请求URL                                           |
| request_params  | JSON            | -                  | NULL              | 请求参数                                          |
| response_status | INT             | -                  | NULL              | 响应状态                                          |
| response_time   | INT             | -                  | NULL              | 响应时间(毫秒)                                    |
| success         | TINYINT(1)      | -                  | 1                 | 是否成功                                          |
| error_message   | TEXT            | -                  | NULL              | 错误信息                                          |
| created_at      | DATETIME        | NOT NULL           | CURRENT_TIMESTAMP | 创建时间                                          |
