## 2. 资源组功能设计

支持用户对项目资源进行分组管理，通过资源组的管理可以控制不同项目、项目成员对资源的使用。

- **功能描述**

1. 【资源组查询】

支持分页查询和多条件筛选，查询条件包括：

| 查询条件   | 示例   | 描述                                         |
| ---------- | ------ | -------------------------------------------- |
| 搜索       | 关键词 | 文本输入框，支持资源组名称的精确或模糊查询。 |
| 资源组状态 | 启用   | 单选下拉选项，支持按状态筛选（启用/禁用）。  |
| 更新时间   | 近7天  | 日期范围选择器，支持按更新时间范围筛选。     |

2. 【资源组列表】

按照创建时间倒序排列，以列表方式展示资源组信息，展示信息包括：

- 资源组名称、资源组描述、资源数量、创建时间、创建用户、更新时间。
- 操作按钮：查看资源、编辑、启用/禁用、删除。

1. 【资源组新增】

支持创建新资源组：

- 【基本信息】资源组名称、资源组描述、资源组状态。
- 【资源分配】选择归属到该资源组的具体资源。

4. 【资源组修改】

支持对资源组信息的修改：

- 【基本信息修改】资源组名称、描述、状态。
- 【资源管理】添加或移除资源组中的资源。

5. 【资源组删除】

支持资源组的安全删除：

- 【删除检查】检查资源组是否有关联的资源或正在使用，非空的资源组不允许直接删除。
- 【确认删除】需要管理员二次确认删除操作。
- 【删除审计】记录资源组删除操作的审计日志。

6. 【资源管理】

支持资源组内资源的管理：

- 【查看资源】展示资源组内所有资源列表。
- 【添加资源】向资源组添加新资源。
- 【移除资源】从资源组移除资源。
- 【批量操作】支持批量添加或移除资源。

## 3. 资源组接口设计

**获取资源组列表**

```text
GET /api/v1/resource-groups
```

查询参数：

| 参数      | 类型    | 必填 | 默认值 | 描述       |
| --------- | ------- | ---- | ------ | ---------- |
| page      | integer | 否   | 1      | 页码       |
| page_size | integer | 否   | 20     | 每页数量   |
| keyword   | string  | 否   | -      | 搜索关键词 |
| owner_id  | integer | 否   | -      | 所有者ID   |

响应示例：


**创建资源组**

```text
POST /api/v1/resource-groups
```

请求体参数：

| 参数名      | 数据类型 | 是否可空 | 描述       |
| ----------- | -------- | -------- | ---------- |
| name        | string   | 否       | 资源组名称 |
| code        | string   | 否       | 资源组编码 |
| description | string   | 是       | 资源组描述 |
| sort_order  | integer  | 是       | 排序顺序   |

**获取资源组详情**

```text
GET /api/v1/resource-groups/{id}
```

**更新资源组**

```text
PUT /api/v1/resource-groups/{id}
```

**删除资源组**

```text
DELETE /api/v1/resource-groups/{id}
```

**获取资源组资源列表**

```text
GET /api/v1/resource-groups/{id}/resources
```

查询参数：

| resource_type | string | 否   | -      | 资源类型（SERVER, SECRET_KEY, DATABASE, APP_GATEWAY, CLOUD_RESOURCE, APP_INSTANCE） |

**移动资源到资源组**

```text
POST /api/v1/resource-groups/{id}/resources
```

请求体参数：

| 参数名        | 数据类型  | 是否可空 | 描述                                       |

## 4. 资源组数据库设计

**资源组表（resource_groups）**

| 字段名      | 类型            | 约束               | 默认值                                        | 注释                 |
| ----------- | --------------- | ------------------ | --------------------------------------------- | -------------------- |
| id          | BIGINT UNSIGNED | PK, AUTO_INCREMENT | -                                             | 资源组ID             |
| project_id  | BIGINT UNSIGNED | NOT NULL, FK       | -                                             | 项目ID               |
| name        | VARCHAR(64)     | NOT NULL           | -                                             | 资源组名称           |
| code        | VARCHAR(32)     | NOT NULL, UNIQUE   | -                                             | 资源组编码           |
| description | TEXT            | -                  | NULL                                          | 资源组描述           |
| owner_id    | BIGINT UNSIGNED | NOT NULL, FK       | -                                             | 所有者ID             |
| sort_order  | INT             | -                  | 0                                             | 排序                 |
| status      | TINYINT(1)      | -                  | 1                                             | 状态：0-禁用，1-启用 |
| created_at  | DATETIME        | NOT NULL           | CURRENT_TIMESTAMP                             | 创建时间             |
| updated_at  | DATETIME        | NOT NULL           | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间             |

### 5.1 资源类型常量定义

资源组支持管理以下资源类型：

| 常量值         | 中文名称 | 描述                           | 关联表             |
| -------------- | -------- | ------------------------------ | ------------------ |
| SERVER         | 服务器   | 物理服务器或虚拟机             | servers            |
| SECRET_KEY     | 密钥     | 访问密钥、证书等敏感信息       | secret_keys        |
| DATABASE       | 数据库   | 数据库连接配置                 | database_connections |
| APP_GATEWAY    | 应用网关 | 应用网关服务                   | app_gateways       |
| CLOUD_RESOURCE | 云资源   | 云平台资源（虚拟机、存储等）   | cloud_resources    |
| APP_INSTANCE   | 应用实例 | 部署的应用实例                 | app_instances      |

**使用示例：**

```json
{
  "resource_type": "SERVER",
  "resource_ids": [1, 2, 3]
}
```

**枚举定义（Go）：**

```go
// ResourceType 资源类型
type ResourceType string

const (
    ResourceTypeServer        ResourceType = "SERVER"         // 服务器
    ResourceTypeSecretKey     ResourceType = "SECRET_KEY"     // 密钥
    ResourceTypeDatabase      ResourceType = "DATABASE"       // 数据库
    ResourceTypeAppGateway    ResourceType = "APP_GATEWAY"    // 应用网关
    ResourceTypeCloudResource ResourceType = "CLOUD_RESOURCE" // 云资源
    ResourceTypeAppInstance   ResourceType = "APP_INSTANCE"   // 应用实例
)

// ValidResourceTypes 有效的资源类型列表
var ValidResourceTypes = []ResourceType{
    ResourceTypeServer,
    ResourceTypeSecretKey,
    ResourceTypeDatabase,
    ResourceTypeAppGateway,
    ResourceTypeCloudResource,
    ResourceTypeAppInstance,
}
```

### 5.2 资源统计字段说明

资源组列表接口返回的 `resource_counts` 对象包含以下字段：

| 字段名          | 类型    | 描述           |
| --------------- | ------- | -------------- |
| servers         | integer | 服务器数量     |
| secret_keys     | integer | 密钥数量       |
| databases       | integer | 数据库数量     |
| app_gateways    | integer | 应用网关数量   |
| cloud_resources | integer | 云资源数量     |
| app_instances   | integer | 应用实例数量   |
| total           | integer | 资源总数       |
