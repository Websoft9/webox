## 2. 密钥管理功能设计

密钥管理是平台提供给用户的密码保管箱，在应用持续部署、应用运维管理等场景中省去用户重复的密码输入、授权操作。

- **功能描述**

1. 【密钥查询】

支持分页查询和多条件筛选，查询条件包括：

| 查询条件 | 示例     | 描述                                                       |
| -------- | -------- | ---------------------------------------------------------- |
| 搜索     | 关键词   | 文本输入框，支持密钥名称、描述信息、用户的精确或模糊查询。 |
| 密钥类型 | 账号密码 | 多选下拉选项，支持按密钥类型筛选。                         |
| 授权状态 | 已授权   | 单选下拉选项，支持按授权状态筛选。                         |
| 更新时间 | 近7天    | 日期范围选择器，支持按更新时间范围筛选。                   |

2. 【密钥列表】

按照创建时间倒序排列，以列表方式展示密钥信息，展示信息包括：

- 密钥名称、密钥类型、创建用户、创建时间。
- 操作按钮：查看、编辑、授权、删除、导出。

3. 【密钥创建】

支持创建不同类型的密钥：

- 【账号密码类型】
  - 用户名：文本输入框
  - 密码：密码输入框，支持随机生成
  - 确认密码：密码确认输入框

- 【密钥/令牌类型】
  - 密钥内容：文本域输入框，支持多行输入
  - 密钥格式：下拉选择（API Key、Access Token、JWT等）

- 【证书类型】
  - 证书文件：文件上传组件
  - 私钥文件：文件上传组件（可选）
  - 证书密码：密码输入框（可选）

- 【自定义字段类型】
  - 字段名称：文本输入框
  - 字段值：文本输入框
  - 字段类型：下拉选择（文本、密码、URL等）

1. 【密钥授权管理】

支持对密钥进行细粒度的授权管理：

- 【用户授权】选择可以使用该密钥的用户列表。
- 【用户组授权】选择可以使用该密钥的用户组列表。
- 【权限级别】只读权限。
- 【使用范围】限制密钥的使用场景（工作流/应用部署/服务器管理）。
- 【有效期限】设置授权的有效期限。

6. 【密钥修改】

支持对密钥信息的修改：

- 【基本信息修改】密钥名称、描述信息的修改。
- 【授权规则修改】授权用户、权限级别、使用范围的修改。
- 【密钥内容修改】密钥值的更新（需要权限验证）。
- 【过期时间修改】设置或修改密钥的过期时间。

7. 【密钥删除】

支持密钥的安全删除：

- 【使用检查】检查密钥是否正在被工作流或应用使用。
- 【确认删除】需要用户二次确认删除操作。
- 【强制删除】管理员可以强制删除正在使用的密钥。
- 【删除审计】记录密钥删除操作的审计日志。

8. 【密钥导出】

支持密钥的安全导出：

- 【权限验证】只有密钥创建者或管理员可以导出。
- 【导出格式】支持JSON、YAML格式导出。
- 【敏感数据处理】导出时对敏感内容进行加密处理。
- 【导出审计】记录密钥导出操作的审计日志。

- **业务流程**

密钥使用流程：

1. 工作流或应用请求使用密钥。
2. 验证请求用户的使用权限。
3. 检查密钥的有效期和使用范围。
4. 解密密钥内容并返回。
5. 记录密钥使用日志。
6. 更新密钥使用统计信息。

密钥授权流程：

1. 密钥创建者或管理员设置授权规则。
2. 选择授权用户或用户组。
3. 设置权限级别和使用范围。
4. 验证授权配置的有效性。
5. 保存授权配置。
6. 通知被授权用户。
7. 记录授权操作审计日志。

- **技术实现**

【密钥加密存储】

使用RSA256算法对敏感数据进行加密存储，加密密钥为用户信息字段的随机密码，创建用户时自动生成，对用户不可见且不可修改。

## 3. 密钥管理接口设计

**接口名称1**

**获取密钥列表**

```text
GET /api/v1/secret-keys
```

查询参数：

| 参数      | 类型    | 必填 | 默认值 | 描述     |
| --------- | ------- | ---- | ------ | -------- |
| page      | integer | 否   | 1      | 页码     |
| page_size | integer | 否   | 20     | 每页数量 |
| key_type  | string  | 否   | -      | 密钥类型 |

响应示例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 1,
        "name": "数据库连接密钥",
        "key_type": "ACCOUNT",
        "description": "MySQL数据库连接密钥",
        "is_encrypted": true,
        "authorized_users": [1, 2],
        "authorized_groups": [1],
        "expires_at": "2025-04-01T00:00:00Z",
        "owner_id": 1,
        "created_at": "2024-10-01T00:00:00Z",
        "updated_at": "2025-07-15T10:30:00Z"
      }
    ]
  }
}
```

**创建密钥**

```text
POST /api/v1/secret-keys
```

请求体参数：

| 参数名            | 数据类型 | 是否可空 | 描述           |
| ----------------- | -------- | -------- | -------------- |
| name              | string   | 否       | 密钥名称       |
| key_type          | string   | 否       | 密钥类型       |
| resource_group_id | integer  | 否       | 资源ID         |
| description       | string   | 是       | 密钥描述       |
| custom_fields     | object   | 是       | 自定义字段     |
| authorized_users  | array    | 是       | 授权用户ID列表 |
| expires_at        | string   | 是       | 过期时间       |

创建密钥请求示例：

- **TOKEN**

```json
{
  "key_type": "TOKEN",
  "custom_fields": {
    "token_key": "sk-1234567890abcdef",
  }
}
```

- **ACCOUNT**

```json
{
  "key_type": "ACCOUNT",
  "custom_fields":{
    "username": "root",
    "password": "123456",
  }
}
```

- **FILE**

文件上传：

请求体（multipart/form-data）：

```text
file: [文件内容]
path: /home/user/
```

>
> 支持的文件类型：
>
> .key
> .pem
> .ras
> .crt
>

response:

```json
{
  "code": 200,
  "message": "success",
  "filename": "2345678ioasjhhdvgajdjknasd.key"
}
```

创建文件密钥：

```json
{
  "key_type": "FILE",
  "custom_fields":{
    "filename": "2345678ioasjhhdvgajdjknasd.key",
    "password": "abc1234",
  }
}
```

**更新密钥**

```text
PUT /api/v1/secret-keys/{id}
```

请求体参数：

| 参数名        | 数据类型 | 是否可空 | 描述       |
| ------------- | -------- | -------- | ---------- |
| custom_fields | object   | 是       | 自定义字段 |
| key_type      | string   | 否       | 密钥类型   |

**删除密钥**

```text
DELETE /api/v1/secret-keys/{id}
```

**获取密钥值**

```text
GET /api/v1/secret-keys/{id}/value
```

响应：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "value": "sk-1234567890abcdef",
    "expires_at": "2025-02-21T10:30:00Z"
  }
}
```

**导出密钥**

```text
GET /api/v1/secret-keys/export
```

查询参数：

| 参数   | 类型   | 必填 | 默认值 | 描述                         |
| ------ | ------ | ---- | ------ | ---------------------------- |
| format | string | 否   | csv    | 导出格式（csv, excel, json） |

响应：

```text
Content-Type: application/octet-stream
Content-Disposition: attachment; filename="secret-keys-20250122.csv"
```

## 4. 密钥管理数据库设计

**密钥管理表（secret_keys）**

| 字段名            | 类型            | 约束               | 默认值                                        | 注释       |
| ----------------- | --------------- | ------------------ | --------------------------------------------- | ---------- |
| id                | BIGINT UNSIGNED | PK, AUTO_INCREMENT | -                                             | 密钥ID     |
| name              | VARCHAR(64)     | NOT NULL           | -                                             | 密钥名称   |
| key_type          | ENUM            | NOT NULL           | -                                             | 密钥类型   |
| description       | TEXT            | -                  | NULL                                          | 描述       |
| custom_fields     | JSON            | -                  | NULL                                          | 自定义字段 |
| expires_at        | DATETIME        | -                  | NULL                                          | 过期时间   |
| resource_group_id | BIGINT UNSIGNED | FK                 | NULL                                          | 资源组ID   |
| owner_id          | BIGINT UNSIGNED | NOT NULL, FK       | -                                             | 所有者ID   |
| created_at        | DATETIME        | NOT NULL           | CURRENT_TIMESTAMP                             | 创建时间   |
| updated_at        | DATETIME        | NOT NULL           | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间   |

## 5. 附录

### 5.1 密钥类型

| 密钥类型 | 描述                                                                 |
| -------- | -------------------------------------------------------------------- |
| TOKEN    | 密钥为字符串，如API Key、Access Key、Secret Key等                    |
| ACCOUNT  | 密钥为账号密码，如用户名、密码、数据库名、数据库用户名、数据库密码等 |
| FILE     | 密钥为文件，如公钥、私钥、证书等                                     |
