## 1. 引言

本文档为 **Websoft9架构升级** 的数据库设计文档，本文档的编写目的在于明确 **Websoft9架构升级** 需求的开发途径以及应用方法，通过此文档，为此 **Websoft9架构升级** 需求的维护提供清晰、详细的设计，为下阶段开发工作的开展起到指导作用。

本文档的预期读者是 **Websoft9架构升级** 需求相关的业务人员、开发人员以及系统运维人员。

## 2. 数据库技术规范

### 2.1 数据库选型

根据架构设计要求，Websoft9平台采用以下数据库技术栈：

| 数据库类型       | 技术选型   | 版本要求 | 用途说明                             |
| ---------------- | ---------- | -------- | ------------------------------------ |
| **关系型数据库** | MySQL      | 8.0+     | 存储平台配置数据、用户数据、业务数据 |
| **关系型数据库** | PostgreSQL | 13.0+    | 可选，支持作为MySQL的替代方案        |
| **内存数据库**   | Redis      | 6.0+     | 缓存数据、会话数据、消息队列         |
| **时序数据库**   | InfluxDB   | 2.0+     | 监控数据、性能指标、审计日志         |

### 2.2 命名规范

**表命名规范：**

- 采用小写字母和下划线分隔
- 表名使用复数形式
- 系统表以 `sys_` 为前缀
- 业务表以业务模块简称为前缀
- 示例：`users`, `sys_configs`, `app_instances`

**字段命名规范：**

- 采用小写字母和下划线分隔
- 主键统一命名为 `id`
- 外键命名为 `表名_id`
- 布尔类型字段以 `is_` 或 `has_` 开头
- 时间字段以 `_at` 或 `_time` 结尾
- 示例：`user_id`, `is_active`, `created_at`

**索引命名规范：**

- 主键索引：`pk_表名`
- 唯一索引：`uk_表名_字段名`
- 普通索引：`idx_表名_字段名`
- 外键索引：`fk_表名_外键字段名`

### 2.3 数据类型规范

**字符类型：**

- 短文本字段（≤255字符）：`VARCHAR(255)`
- 长文本字段：`TEXT`
- 固定长度字符：`CHAR(n)`
- JSON数据：`JSON`

**数值类型：**

- 主键ID：`BIGINT UNSIGNED AUTO_INCREMENT`
- 整数：`INT`
- 长整数：`BIGINT`
- 小数：`DECIMAL(10,2)`
- 布尔值：`TINYINT(1)`

**时间类型：**

- 日期时间：`DATETIME`
- 时间戳：`TIMESTAMP`
- 日期：`DATE`

### 2.4 字符集和排序规则

- **字符集**：`utf8mb4`
- **排序规则**：`utf8mb4_unicode_ci`
- **存储引擎**：`InnoDB`

### 2.5 索引规范

**主键索引：**

- 每个表必须有主键
- 主键使用自增整型
- 主键字段命名为 `id`

**外键索引：**

- 外键字段必须建立索引
- 外键约束采用软约束（应用层控制）

**查询索引：**

- 频繁查询的字段建立索引
- 联合索引遵循最左前缀原则
- 避免在低选择性字段上建立索引

### 2.6 数据库设计原则

**规范化原则：**

- 遵循第三范式（3NF）
- 适当的反规范化以提高查询性能
- 避免数据冗余

**性能优化原则：**

- 合理设计索引
- 避免使用SELECT *
- 大表分页查询
- 定期优化查询语句

**安全性原则：**

- 敏感数据加密存储
- 数据库用户权限最小化
- 定期备份数据
- 启用慢查询日志

### 2.7 数据备份与恢复

**备份策略：**

- 全量备份：每日凌晨执行
- 增量备份：每小时执行
- 备份保留期：30天
- 异地备份：重要数据异地存储

**恢复策略：**

- 支持点对点恢复
- 灾难恢复预案
- 数据恢复测试

## 4. 附录

### 4.1 状态字典定义

**记录状态定义**

全局的表记录状态字段`status`通用定义：业务记录统一为软删除，关系记录或非业务关键记录统一为硬删除（通常情况下这类表不存在`status`字段）。

如果存在其他类型记录状态码，按照相应的业务逻辑自行定义。

| 状态名称 | 状态字典 | 描述                     |
| -------- | -------- | ------------------------ |
| `已删除` | -1       | 记录被删除，不可以读写。 |
| `禁用`   | 0        | 记录被禁用，可读不可以写。   |
| `启用`   | 1        | 默认状态，可以读写。     |

**应用状态定义**

| 状态名称 | 状态字典   | 描述                                                        |
| -------- | ---------- | ----------------------------------------------------------- |
| `默认`   | DEFAULT    | 默认状态，即未部署的初始状态，当应用被卸载后重置为DEFAULT。 |
| `未知`   | UNKNOWN    | 未知状态，应用失联或网络不可达时的状态。                    |
| `已部署` | DEPLOYMENT | 从应用商店下载并且部署安装的状态。                          |
| `运行中` | RUNNING    | 已部署并且已启动。                                          |
| `已暂停` | PAUSED     | 仅容器应用，暂停的状态。                                    |
| `已停止` | STOPPED    | 已停止运行的状态。                                          |
| `更新中` | UPDATE     | 仅容器应用，正在更新的状态。                                |

**服务器状态定义**

| 状态名称 | 状态字典 | 描述                                       |
| -------- | -------- | ------------------------------------------ |
| `未知`   | UNKNOWN  | 未知状态，服务器失联或网络不可达时的状态。 |
| `运行中` | RUNNING  | 服务器运行中。                             |
| `已停止` | STOPPED  | 已停止运行。                               |
