## 2. 通知管理功能设计

### 2.1 推送通知配置

支持管理员对平台各功能/服务的推送通知进行统一配置和管理，确保重要信息能及时准确地触达目标用户。

- **功能描述**

1. 【通知方式配置】

支持多种通知推送方式的配置：

| 通知方式 | 是否必选 | 描述                             |
| -------- | -------- | -------------------------------- |
| 站内信   | 必选     | 系统内部消息推送，用户登录可查看 |
| 邮件     | 可选     | 通过邮件服务推送到用户邮箱       |
| Webhook  | 可选     | 通过Webhook推送到指定URL         |

1. 【通知范围配置】

支持不同类型业务场景的通知推送：

- **应用市场推送**：新应用的营销推广、已部署应用的新版本更新通知。
- **平台服务推送**：平台服务/组件的版本更新通知。
- **工作流任务推送**：任务执行完成/异常的进度通知。
- **系统状态推送**：文件上传成功、服务器重启完成、License到期提醒等一般性功能状态更新通知。

3. 【通知频率控制】

支持通知推送的频率控制策略：

- **即时推送**：默认通知为即时推送。
- **免打扰模式**：在指定时间段内暂停非紧急通知的推送。
- **频率限制**：对同一类型通知设置推送频率上限。

4. 【通知设置管理】

支持通知配置的统一管理：

- **查看配置**：展示当前所有通知类型的配置状态。
- **修改配置**：支持修改通知方式、范围和频率设置。
- **测试推送**：支持发送测试通知验证配置是否正确。

### 2.2 告警通知模板配置

支持管理员自定义告警类通知模板，通过模板变量实现灵活的内容定制和统一的消息格式管理。

- **功能描述**

1. 【模板查询】

支持分页查询和多条件筛选，查询条件包括：

| 查询条件 | 示例     | 描述                                          |
| -------- | -------- | --------------------------------------------- |
| 搜索     | 关键词   | 文本输入框，支持模板名称的精确或模糊查询。    |
| 模板类型 | 邮件模板 | 单选下拉选项，支持按类型筛选（邮件/站内信）。 |
| 模板状态 | 启用     | 单选下拉选项，支持按状态筛选（启用/禁用）。   |
| 更新时间 | 近7天    | 日期范围选择器，支持按更新时间范围筛选。      |

2. 【模板列表】

按照更新时间倒序排列，以列表方式展示模板信息，展示信息包括：

- 模板名称、模板类型、通知主题、模板状态、创建时间、更新时间。
- 操作按钮：查看详情、编辑、复制、测试、启用/禁用、删除。

3. 【模板新增】

支持创建新的通知模板：

- **基本信息**：模板名称、模板类型、通知主题、模板描述。
- **模板内容**：主题模板、正文模板、变量定义。
- **变量配置**：支持预定义变量和自定义变量。
- **格式预览**：实时预览模板渲染效果。

4. 【模板修改】

支持对模板内容的修改：

- **基本信息修改**：名称、描述、状态等基础信息。
- **内容编辑**：模板主题和正文的编辑，支持富文本编辑器。
- **变量管理**：添加、修改、删除模板变量。

5. 【模板删除】

支持模板的安全删除：

- **删除检查**：检查模板是否被通知规则引用，有引用的模板不允许直接删除。
- **删除限制**：系统预置模板不允许删除。
- **删除审计**：记录模板删除操作的审计日志。

6. 【变量替换功能】

支持模板中的动态变量替换：

- **系统变量**：平台名称、当前时间、操作用户等系统级变量。
- **业务变量**：应用名称、服务器信息、任务状态等业务相关变量。
- **变量验证**：确保模板中使用的变量都有对应的数据源。

7. 【预置模板】

平台预置的示例模板：

| 模板名称         | 通知主题   | 主要变量                        |
| ---------------- | ---------- | ------------------------------- |
| 应用部署成功通知 | 应用管理   | 应用名称、部署时间、访问地址    |
| 服务器告警通知   | 监控告警   | 服务器名称、告警类型、告警时间  |
| 工作流执行通知   | 工作流管理 | 工作流名称、执行状态、执行时间  |
| License到期提醒  | 系统管理   | License类型、到期时间、剩余天数 |

### 2.3 通知渠道配置

支持多种通知渠道的配置和管理，为不同类型的通知提供灵活的推送方式选择。

- **功能描述**

1. 【邮件渠道配置】

支持SMTP邮件服务配置，用于系统通知推送：

- **SMTP基础配置**：服务器地址、端口号、加密方式（SSL/TLS）、连接超时。
- **认证配置**：发件人邮箱、发件人名称、SMTP用户名、SMTP密码。
- **高级配置**：字符编码、发送频率限制、重试次数。
- **配置管理**：查看当前配置、编辑配置、测试连接。
- **邮件模板管理**：系统预置模板、自定义模板编辑、变量预览、测试发送。

1. 【Webhook渠道配置】

支持Webhook服务配置，便于外部系统集成和自动化触发：

- **服务配置**：服务开关、监听端口、URL路径、安全配置。
- **安全设置**：IP白名单、API认证、请求频率限制、请求超时。
- **Webhook管理**：查询现有配置、创建新配置、编辑配置、测试调用、启用/禁用、删除配置。
- **事件触发**：工作流状态变更、系统任务执行、应用部署事件、服务器操作事件、告警处理事件。
- **数据格式**：HTTP POST请求、JSON数据格式、认证头信息、自定义参数。

## 3. 通知管理接口设计

### 3.1 通知渠道配置

> 通知配置（策略）与通知渠道对应，即一个通知渠道对应一种通知策略。

**获取渠道配置列表**

```text
GET /api/v1/notifications/channels
```

查询参数：

| 参数名           | 数据类型 | 是否可空 | 描述                         |
| ---------------- | -------- | -------- | ---------------------------- |
| page             | integer  | 是       | 页码，默认1                  |
| page_size        | integer  | 是       | 每页数量，默认20，最大100    |
| channel_channels | string   | 是       | 渠道类型（EMAIL/WEBHOOK）    |
| status           | integer  | 是       | 状态筛选：0-禁用，1-启用     |
| search           | string   | 是       | 搜索关键词，支持名称模糊查询 |

响应示例：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "items": [
      {
        "id": 1,
        "code": "aliyun_email",
        "channel_channels": "EMAIL",
        "channel_config": "{ .... }",
        "status": 1,
        "created_at": "2025-01-01 10:00:00",
        "updated_at": "2025-01-01 10:00:00"
      }
    ],
    "total": 8,
    "page": 1,
    "page_size": 20,
    "total_pages": 1
  }
}
```

**创建渠道配置**

```text
POST /api/v1/notifications/channels
```

- **EMAIL**

请求体参数：

| 参数名          | 数据类型 | 是否可空 | 描述                           |
| --------------- | -------- | -------- | ------------------------------ |
| code            | string   | 否       | 渠道配置编码（唯一标识）       |
| channel_type    | string   | 否       | 渠道类型（EMAIL）              |
| channel_config  | object   | 否       | 渠道配置参数                   |
| - smtp_host     | string   | 否       | SMTP服务器地址                 |
| - smtp_port     | integer  | 否       | SMTP端口号                     |
| - smtp_security | string   | 是       | 加密方式：none/ssl/tls         |
| - smtp_timeout  | integer  | 是       | 连接超时时间，默认30秒         |
| - smtp_username | string   | 否       | SMTP用户名                     |
| - smtp_password | string   | 否       | SMTP密码                       |
| - sender_email  | string   | 否       | 发件人邮箱                     |
| - sender_name   | string   | 是       | 发件人名称                     |
| - encoding      | string   | 是       | 字符编码，默认utf-8            |
| - rate_limit    | integer  | 是       | 发送频率限制，每小时最大发送数 |
| - retry_count   | integer  | 是       | 重试次数，默认3                |
| - quiet_hours   | string   | 是       | 免打扰时间段                   |

请求示例：
