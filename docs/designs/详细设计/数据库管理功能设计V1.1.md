## 2. 数据库管理功能设计

支持用户按需接入数据库，提供对数据库的操作界面，提供对接入数据库信息的配置。

- **功能描述**

1. 【数据库接入】

支持接入多种关系型数据库：

| 数据库类型 | 支持版本   | 接入方式                      |
| ---------- | ---------- | --------------------------- |
| MariaDB    |            | 平台部署的应用 / 外部云数据库 |
| SQL Server |            | 平台部署的应用 / 外部云数据库 |
| Oracle     |            | 平台部署的应用 / 外部云数据库 |
| MySQL      | 5.7, 8.0   | 平台部署的应用 / 外部云数据库 |
| PostgreSQL | 12, 13, 14 | 平台部署的应用 / 外部云数据库 |

接入配置参数：
- 【连接信息】主机地址、端口、数据库名称
- 【认证信息】用户名、密码

1. 【数据库列表】

展示已接入的数据库连接，包含信息：

- 数据库名称、类型、版本信息。
- 连接状态、最后连接时间。
- 所属应用或外部标识。
- 权限级别、所属资源组。
- 操作按钮：连接、配置、测试连接、删除。

3. 【数据库操作界面】

集成第三方数据库管理面板，提供Web版数据库管理工具。支持所有主流数据库的统一管理。

- **业务流程**

数据库接入流程：

1. 用户选择数据库类型并填写连接信息。
2. 系统测试数据库连接可用性。
3. 验证用户权限和可访问的数据库。
4. 保存连接配置并加密存储密码。
5. 完成接入并进入数据库管理面板。

- **集成工具说明**

Websoft9 集成 Adminer 作为统一的数据库管理工具，支持以下数据库：

| 数据库类型 | 支持情况 | 说明 |
|----------|---------|------|
| MySQL | ✅ 完全支持 | 包括 5.7, 8.0 及以上版本 |
| MariaDB | ✅ 完全支持 | 完全兼容 MySQL |
| PostgreSQL | ✅ 完全支持 | 包括 12, 13, 14 及以上版本 |
| SQL Server | ✅ 完全支持 | 2012 及以上版本 |
| Oracle | ✅ 完全支持 | 11g 及以上版本 |
| SQLite | ✅ 完全支持 | 文件数据库 |

使用 Adminer 的优势：
- 单一工具支持所有数据库
- 轻量级部署（单 PHP 文件）
- 无需额外认证系统
- 与 Websoft9 权限系统集成
- 自动填表登录，用户体验无缝

## 3. 数据库管理接口设计

### 3.0 API 列表

| 编号 | 方法 | 端点 | 说明 |
|------|------|------|------|
| 3.1 | GET | `/api/v1/database-connections` | 获取数据库连接列表 |
| 3.2 | POST | `/api/v1/database-connections` | 添加数据库连接 |
| 3.3 | GET | `/api/v1/database-connections/{id}` | 获取连接详情 |
| 3.4 | PUT | `/api/v1/database-connections/{id}` | 更新数据库连接 |
| 3.5 | DELETE | `/api/v1/database-connections/{id}` | 删除数据库连接 |
| 3.6 | POST | `/api/v1/database-connections/test-connection` | 测试数据库连接 |
| 3.7 | GET | `/api/v1/database-connections/{id}/open-admin` | 打开数据库管理工具 |

## 4. 数据库管理数据库设计

### 4.1 核心表设计

**数据库连接表（database_connections）**

| 字段名 | 类型 | 约束 | 默认值 | 注释 |
|--------|------|------|--------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | - | 连接ID |
| name | VARCHAR(64) | NOT NULL, UNIQUE(owner_id, name) | - | 连接名称 |
| db_type | VARCHAR(32) | NOT NULL | - | 数据库类型 |
| host | VARCHAR(255) | - | NULL | 主机地址 |
| port | INT | - | NULL | 端口号 |
| database | VARCHAR(64) | - | NULL | 数据库名称 |
| username | VARCHAR(64) | - | NULL | 用户名 |
| password | VARCHAR(255) | - | NULL | 加密密码 |
| resource_group_id | BIGINT UNSIGNED | FK | NULL | 资源组ID |
| owner_id | BIGINT UNSIGNED | NOT NULL, FK | - | 所有者ID |
| created_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**表索引设计**

```sql
-- 主键
PRIMARY KEY (id)

-- 唯一索引
UNIQUE KEY uk_owner_name (owner_id, name)

-- 查询索引
KEY idx_owner_id (owner_id)
KEY idx_db_type (db_type)
KEY idx_resource_group_id (resource_group_id)

-- 外键
FOREIGN KEY (owner_id) REFERENCES users(id) ON DELETE RESTRICT
FOREIGN KEY (resource_group_id) REFERENCES resource_groups(id) ON DELETE SET NULL
```

## 5. 附录

### 5.1 枚举值定义

**数据库类型（db_type）**

| 类型 | 说明 |
|------|------|
| mysql | MySQL 5.7, 8.0 及以上 |
| postgresql | PostgreSQL 12, 13, 14 及以上 |
| mariadb | MariaDB 10.x 及以上 |
| sqlserver | SQL Server 2012 及以上 |
| oracle | Oracle 11g 及以上 |
| sqlite | SQLite 3.x |

---

### 5.2 权限控制说明

**获取连接列表**：
- 普通用户只能查看自己所有的连接（owner_id = current_user_id）
- 管理员可以查看所有连接

**创建连接**：
- 普通用户只能创建以自己为所有者的连接
- 需要 `database:create` 权限

**修改/删除连接**：
- 只能操作自己所有的连接
- 需要对应的 `database:edit` 或 `database:delete` 权限

---

### 5.3 密码安全说明

- 密码字段使用 AES-256-GCM 加密算法进行加密
- API 响应中**永不返回** `password` 字段
- 修改密码时需要完整的凭证验证
- 敏感信息在传输中必须使用 HTTPS 加密

### 5.4 Adminer 集成指南

**集成方式**：

1. 前端调用 API：`GET /api/v1/database-connections/{id}/open-admin`
2. API 返回连接参数（host、port、username、password、database 等）
3. 前端构建自动提交表单，提交到 Adminer
4. Adminer 接收参数，自动登录并显示数据库管理界面

**优势**：
- 无需复杂会话管理
- 用户体验无缝
- 实现成本极低

**支持的数据库**：
- MySQL 5.7+
- MariaDB 10.x+
- PostgreSQL 12+
- SQL Server 2012+
- Oracle 11g+
- SQLite 3.x

**前端实现示例**：

```javascript
async function openAdminTool(connectionId) {
  const response = await fetch(
    `/api/v1/database-connections/${connectionId}/open-admin`
  );
  const { data } = await response.json();
  
  // 构建表单
  const form = document.createElement('form');
  form.method = 'POST';
  form.action = '/admin/adminer.php';
  form.target = '_blank';
  
  // 填充参数
  Object.entries(data).forEach(([key, value]) => {
    const input = document.createElement('input');
    input.type = 'hidden';
    input.name = key;
    input.value = value;
    form.appendChild(input);
  });
  
  document.body.appendChild(form);
  form.submit();
  document.body.removeChild(form);
}
```
