## 2. 数据库管理功能设计

支持用户按需接入数据库，提供对数据库的操作界面，提供对接入数据库信息的配置。

- **功能描述**

1. 【数据库接入】

支持接入多种类型的数据库：

| 数据库类型 | 支持版本   | 接入方式                      |
| ---------- | ---------- | ----------------------------- |
| MySQL      | 5.7, 8.0   | 平台部署的应用 / 外部云数据库 |
| PostgreSQL | 12, 13, 14 | 平台部署的应用 / 外部云数据库 |
| MongoDB    | 4.4, 5.0   | 平台部署的应用 / 外部云数据库 |
| Redis      | 6.0, 7.0   | 平台部署的应用 / 外部云数据库 |

接入配置参数：

- 【连接信息】数据库类型、主机地址、端口、数据库名称。
- 【认证信息】用户名、密码、SSL证书（可选）。
- 【连接池配置】最大连接数、连接超时时间、空闲超时时间。
- 【权限设置】只读/读写权限、允许操作的数据库列表。

2. 【数据库列表】

展示已接入的数据库连接，包含信息：

- 数据库名称、类型、版本信息。
- 连接状态、最后连接时间。
- 所属应用或外部标识。
- 权限级别、所属资源组。
- 操作按钮：连接、配置、测试连接、删除。

3. 【数据库操作界面】

集成第三方数据库管理面板，提供Web版数据库管理工具。

- **业务流程**

数据库接入流程：

1. 用户选择数据库类型并填写连接信息。
2. 系统测试数据库连接可用性。
3. 验证用户权限和可访问的数据库。
4. 保存连接配置并加密存储密码。
5. 完成接入并进入数据库管理面板。

## 3. 数据库管理接口设计

**获取数据库连接列表**

```text
GET /api/v1/database-connections
```

查询参数：

| 参数      | 类型    | 必填 | 默认值 | 描述                                   |
| --------- | ------- | ---- | ------ | -------------------------------------- |
| page      | integer | 否   | 1      | 页码                                   |
| page_size | integer | 否   | 20     | 每页数量                               |
| db_type   | string  | 否   | -      | 数据库类型（mysql, postgresql, redis） |
| status    | string  | 否   | -      | 连接状态（CONNECTED, DISCONNECTED）    |
| keyword   | string  | 否   | -      | 搜索关键词                             |

**添加数据库连接**

```text
POST /api/v1/database-connections
```

请求体参数：

| 参数名             | 数据类型 | 是否可空 | 描述                                   |
| ------------------ | -------- | -------- | -------------------------------------- |
| name               | string   | 否       | 连接名称                               |
| db_type            | string   | 否       | 数据库类型（mysql, postgresql, redis） |
| host               | string   | 否       | 主机地址                               |
| port               | integer  | 否       | 端口号                                 |
| database           | string   | 是       | 数据库名称                             |
| username           | string   | 否       | 用户名                                 |
| password           | string   | 否       | 密码                                   |
| ssl_enabled        | boolean  | 是       | 是否启用SSL，默认false                 |
| connection_timeout | integer  | 是       | 连接超时时间（秒），默认30             |
| max_connections    | integer  | 是       | 最大连接数，默认10                     |
| description        | string   | 是       | 描述信息                               |

**测试数据库连接**

```text
POST /api/v1/database-connections/test-connection
```

请求体参数：

| 参数名   | 数据类型 | 是否可空 | 描述     |
| -------- | -------- | -------- | -------- |
| host     | string   | 否       | 主机地址 |
| port     | integer  | 否       | 端口号   |
| database | string   | 是       | 数据库名 |
| username | string   | 否       | 用户名   |
| password | string   | 否       | 密码     |

响应示例：

```json
{
  "code": 200,
  "message": "数据库连接测试成功",
  "data": {
    "is_connected": true,
    "response_time": 50,
    "server_version": "8.0.32",
    "server_info": {
      "charset": "utf8mb4",
      "timezone": "Asia/Shanghai"
    }
  }
}
```

**获取数据库详情**

```text
GET /api/v1/database-connections/{id}
```

**更新数据库连接**

```text
PUT /api/v1/database-connections/{id}
```

**删除数据库连接**

```text
DELETE /api/v1/database-connections/{id}
```

## 4. 数据库管理数据库设计

**数据库连接表（database_connections）**

| 字段名             | 类型            | 约束               | 默认值                                        | 注释                                   |
| ------------------ | --------------- | ------------------ | --------------------------------------------- | -------------------------------------- |
| id                 | BIGINT UNSIGNED | PK, AUTO_INCREMENT | -                                             | 连接ID                                 |
| name               | VARCHAR(64)     | NOT NULL           | -                                             | 连接名称                               |
| db_type            | ENUM            | NOT NULL           | -                                             | 数据库类型（mysql, postgresql, redis） |
| host               | VARCHAR(255)    | NOT NULL           | -                                             | 主机地址                               |
| port               | INT             | NOT NULL           | -                                             | 端口号                                 |
| database           | VARCHAR(64)     | -                  | NULL                                          | 数据库名称                             |
| username           | VARCHAR(64)     | -                  | NULL                                          | 用户名                                 |
| password           | VARCHAR(255)    | -                  | NULL                                          | 加密密码                               |
| ssl_enabled        | TINYINT(1)      | -                  | 0                                             | 是否启用SSL                            |
| connection_timeout | INT             | -                  | 30                                            | 连接超时时间(秒)                       |
| max_connections    | INT             | -                  | 10                                            | 最大连接数                             |
| status             | ENUM            | -                  | 'CONNECTED'                                   | 连接状态                               |
| version            | VARCHAR(32)     | -                  | NULL                                          | 数据库版本                             |
| charset            | VARCHAR(32)     | -                  | NULL                                          | 字符集                                 |
| description        | TEXT            | -                  | NULL                                          | 描述信息                               |
| last_connected_at  | DATETIME        | -                  | NULL                                          | 最后连接时间                           |
| resource_group_id  | BIGINT UNSIGNED | FK                 | NULL                                          | 资源组ID                               |
| owner_id           | BIGINT UNSIGNED | NOT NULL, FK       | -                                             | 所有者ID                               |
| created_at         | DATETIME        | NOT NULL           | CURRENT_TIMESTAMP                             | 创建时间                               |
| updated_at         | DATETIME        | NOT NULL           | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间                               |
